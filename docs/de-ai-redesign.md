# 听匣去 AI 味美化方案 — 纸墨书房(Paper & Ink)

> 诊断:当前 UI 是"四个互不相干的温柔色族(墨绿/铜/土金/奶茶)+ 一套教科书
> 均匀间距"的拼贴。改造原则:**收敛色彩、加重字与色、打破均匀**。

## 一、设计令牌

### 色彩(浅色)
| Token | 值 | 用途 |
|---|---|---|
| Ink | #1E2B25 | 唯一主色:播放键、继续卡片、当前章节、进度条、选中态 |
| InkDeep | #14201A | 按下态 |
| Paper | #F7F4ED | 背景(暖纸白,替代冷灰绿 #F4F7F5) |
| PaperCard | #FFFFFF | 卡片 |
| Line | #E3DED2 | 分隔线/描边(暖灰) |
| Muted | #6B6A60 | 次要文字 |
| Mark | #B4432E | 唯一跳色(朱砂):书签、完成标记等"私人痕迹",面积极小 |

删除 Copper 全家、土金按钮、奶茶 chip。规则:一屏之内除 Ink/Mark 外
不允许出现第三个彩色。

### 深色
Night #0B0D0C(近纯黑)/ NightCard #171917 / 主色 #C9DCD0(淡墨绿)。
播放页与详情页的前景强调色改用 Palette API 从封面提取 —— 每本书的
播放页颜色不同。

### 字体
- 书名/章节大标题:FontFamily.Serif(思源宋体)+ SemiBold ← 去 AI 味最重的一笔
- 新增 displayTitle:Serif 26sp, letterSpacing 1sp(详情页书名)
- 时间/章节号:SansSerif + tnum;书架书名字重提一档

### 形状(制造对比,删除等差数列)
封面 6dp(锐利)/ 卡片 18dp / 按钮全胶囊 / Chip 全胶囊 / 对话框 24dp

### 阴影
所有 elevated 元素 spotColor = Ink.copy(alpha=0.12f)(墨绿影);
封面保留现有暖棕影。

## 二、分屏改造

### 书架
- "听匣" 28sp Serif;删除计数小字
- 搜索框改下划线式:透明底 + 底部 1dp Line,放大镜 Ink 色
- chip:未选 1dp Line 描边透明底,选中 Ink 实底白字
- 网格间距 12→9dp;realistic 封面白内框 alpha 0.22→0.10
- "在线"角标:半透明黑胶囊(Black 0.45)+ 白字
- 底部导航选中态:Ink 细顶线 2dp,不用填充药丸

### 详情页
1. "继续播放"土金大按钮 → Ink 深色卡片(与章节卡片同宽同圆角),
   左 icon + Serif 标题 + 副行"续听 020 寻道 · 2:57",作为列表第 0 张卡片
2. 封面 112→132dp,上压背景与卡片交界 12dp
3. 书名 Serif 26sp;"在线真人有声"米色 chip → 半透明黑底白字
4. 章节号灰底方块删除 → 34sp Serif Light 大数字(页码感);
   当前章节整行 Ink 底白字
5. 完成标记:铜色大勾 → Mark 朱砂 14dp 小圆点;未完成 1dp 空心圈
6. 进度条 4→3dp,Ink/Line

### 播放页
1. 封面 0.74→0.82 屏宽,左偏 8dp;右侧竖向放章节序号 Serif Light 64sp
2. 所有文字左对齐,与进度条左端成垂线
3. 控制区沉底(safe-area + 24dp);播放键 Ink 底白 icon(反转现有白底绿 icon)
4. 工具行图标 20dp / 文字 10sp,激活态用封面取色染色
5. 删除顶部"正在播放"小字
6. 倍速按钮直接显示 "1.0×" 点击循环,长按弹完整菜单

### Widget
卡片圆角 12→18dp;播放键色并入 Ink 族(#1E2B25)。

## 三、微交互与文案
- 共享元素转场:书架封面 → 详情封面 → 播放封面
- 封面呼吸 1.015 / 4000ms;暂停缩 0.98 + 饱和度 0.85
- 按钮按下 scaleTo(0.94f) + Ink 加深
- 空状态删 88dp 色块,换线条书脊插画
- 文案:"书架还是空的"→"还没有开始任何一本书";"v0.9.7"格式统一

## 四、实施阶段
- P0 令牌层(半天):Theme.kt 全色板、Serif 排印、形状/阴影
- P1 详情页+播放页(一天)
- P2 书架+组件(半天)
- P3 进阶(一天):封面取色、共享元素、按压物理
- P0+P1 完成即发布 0.10.0
